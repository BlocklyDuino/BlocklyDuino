Put values into inputs

A number block is a default value, not a restriction. Pull it out of its socket and insert a block from Variables, Math or a sensor. Runtime inputs such as position, brightness, duration, image size and pixel shade accept expressions. Device definitions hold physical wiring; operation/type dropdowns select what to do.

Variables and arrays

Use the single Variables category for declarations, values, assignments and arrays. A declaration outside every container is global. A declaration inside a function, setup, loop or control block is local to that enclosing C++ scope. A local in setup is not visible in loop. A loop-local variable is initialized again on each pass.

Array access automatically follows the selected declaration shape; there is no separate multidimensional selector. Each index socket accepts a variable or calculation. Array indices start at zero. For a 4 × 8 array, valid indices are 0–3 and 0–7. The whole array consumes RAM: a 4 × 8 uint8_t array takes 32 bytes; an int array takes 64 bytes on this AVR. The board has 1024 bytes of RAM in total. double has the same precision as float on this board.

Keep several things running

Use millis() and an unsigned long timestamp to schedule work. Long waits stop sensor updates and stepper servicing. Call a loop-engine stepper's run action on every pass; the Timer1 engine services its own queue. DS18B20 supports request/read blocks so a conversion can finish while other work runs.
