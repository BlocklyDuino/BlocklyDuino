Arrange blocks and start again

Board, port and screen space

Open Board & upload port above the workspace. Choose an installed board, its processor or part number, and upload port; click Apply target. Compile and Upload use this saved target, even after restarting the local server. Quick choices cover Pro Mini 168/328P, Pico RP2040 and Blue Pill with OpenOCD ST-Link. Other core-specific menus are under Advanced board options.

For a USB debugger or first Pico UF2 upload use Automatic / USB / debug probe. Normal Pro Mini bootloader upload uses its serial port. The board core controls the upload method; changing the target does not upload or reconnect Serial Monitor. AVR-specific registers and interrupt blocks remain AVR-specific.

Hide toolbox, Examples & guides, board settings and Build output remember their visibility in this browser. Zoom and selection tools remain accessible when the example list is closed. Monitor and Plotter also remember their own settings panels independently.

Zoom and named areas

Use the mouse wheel over the workspace to zoom from 1% to 300% around the pointer. Both zooming out and zooming in keep the same program point under the cursor. Move the pointer to another part of your program and zoom in to inspect it. The toolbar has minus, plus, a percentage button to reset to 100%, and Fit to show all blocks and named areas. The toolbox keeps its normal size.

Use Areas → Add area to draw a rectangle, give it a name, description and colour. Areas save with the project XML and autosave. In Areas mode you can move, resize, edit or delete them. Choose an area and click Show to center and zoom to fit it, even from a distant overview; moving an area does not move its blocks. Named area instructions.

Select and move several stacks

  1. Click Select stacks above the workspace. Drag a rectangle over the stacks you want. You can also start directly with Shift + drag on an empty part of the workspace.
  2. Shift + click adds or removes a stack. Select all selects every top-level stack. The status shows how many stacks and blocks are selected.
  3. Drag any selected stack to move the whole selection together. Their connections and relative spacing stay intact; this mode does not snap them into new connections.
  4. Arrow keys move the selection by 1 workspace unit; Shift + arrows moves by 10. Undo reverses edits, including a group move or nudge. Redo reapplies them.
  5. Click Done selecting or press Escape to return to ordinary block editing. Escape during a drag cancels that drag.

A selection includes whole connected stacks, including nested values and blocks inside setup/loop/functions. This avoids breaking your program while arranging it. To move only a few blocks out of a connected stack, first detach them in ordinary editing mode, then select the resulting independent stacks.

Delete or start empty

Delete selected removes the selected complete stacks after a confirmation. A recovery copy of the whole project is saved first.

New project is always visible above the workspace, and also available in the Project menu. Choose Keep recovery & close or Discard without saving. The old example link and autosave source are cleared too, so refreshing the page keeps the new empty project.

When you choose to keep recovery, the editor saves the current block XML and any unfinished C++ or XML text edits in this browser. Project → Recover blocks lets you restore them or download them. If browser storage is full, the clear operation is cancelled.

Recovery is local to this browser and can disappear if browser/site data is cleared. Use Save blocks and Export C++ for files you want to keep independently. Starting a new project or moving blocks does not upload anything to the board.

Undo and compact views

Use Undo / Redo or Ctrl+Z / Ctrl+Shift+Z (also Ctrl+Y). History includes block edits, deletion, movements, devices, colours and areas; it lasts for this tab session. Inside a text field these shortcuts edit text. Editor-only controls hide in Code, XML and Connections.

Device colours

Click the gear beside an entry in Project devices. Choose its colour and Save. The same colour identifies its blocks and Connections entries. The definition itself contains only relevant device settings.
