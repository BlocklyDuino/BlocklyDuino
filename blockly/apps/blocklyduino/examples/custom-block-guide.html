Add library support

Use device configurations for wiring and functions for reusable logic. An extension is useful when a library has no block support yet.

Edit blockly/apps/blocklyduino/user_blocks.js. It contains a small D13 pulse template. The template is hidden from the normal toolbox until you register it.

  1. Choose a unique block type and add it to window.blocklyduinoUserBlockTypes.
  2. Describe the shape, inputs and tooltip in Blockly.Blocks['type'].
  3. Generate Arduino C++ in Blockly.Arduino.type. Put includes/global objects in definitions_ and hardware initialization in setups_.

Save the file and reload the editor. Registered blocks appear under Extensions. Inspect Code and Compile before uploading. This editor uses an older Blockly API; copy its local templates rather than pasting a modern Blockly example unchanged.
